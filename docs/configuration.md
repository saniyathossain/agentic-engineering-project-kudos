# Configuration reference

Generated by `python3 docs/api/build.py` from `docs/api/envvars.py` and a scan of `codes/config/*.php`. Do not edit by hand.

## How configuration reaches the containers

* **Dev** (`docker/docker-compose.yml`): `docker/.envs/app.env.example` holds the defaults and is bind-mounted into the containers. The `app` container (the only one with `SETUP_ENV=1`) merges it with your private `docker/.envs/app.env` (your values win), generates `APP_KEY` when empty and writes `codes/.env` atomically; `queue` waits for that file. Do not edit `codes/.env` or `app.env` by hand for project settings: add new settings to `app.env.example` (and `app.prod.env.example`).
* **Prod** (`docker-compose.yml` + `docker-compose.prod.yml`, `make prod`): no `.env` file is baked into an image. The container environment comes from `docker/.envs/app.prod.env` (git-ignored; template `app.prod.env.example`), plus `docker/.envs/outage.env` for the two outage values, plus Docker secrets for the database password (`docker/.envs/secrets/db_password`, git-ignored). Any `NAME_FILE=/path` variable is turned into `NAME` by `entrypoint.prod.sh`.
* **Tests** use sqlite in memory through `codes/phpunit.xml`; the compose services must not pass database variables to the test process.
* **Secrets**: keys marked secret below must never be committed. The example files contain only empty values or local demo values (`DB_PASSWORD=kudos`, the seeded demo login).
* **Read by**: `app` = php-fpm or `artisan serve`; `queue` = the queue worker; `scheduler` = prod scheduler; `edge` = nginx; `db` = Postgres; `compose` = read by `docker compose` on the host.

## API collection variables

Set in the Postman environment, the Insomnia environment, or the Bruno environment (`environments/local.bru`, `prod-style.bru`). Variables marked *run time* are written by the scripts during a run; leave them empty. Override on the command line with `--env-var name=value` (newman, Bruno).

| Variable | Default | Set by | Meaning | Secret |
| --- | --- | --- | --- | --- |
| `baseUrl` | `http://localhost:8010` (local), `http://localhost:8011` (prod-style) | environment file | Origin of the app under test, no trailing slash. | no |
| `email` | `demo@kudos.test` | environment file | Owner login. Seeded by DatabaseSeeder; local only. | no |
| `password` | `password` | environment file | Owner password. Seeded local demo value; never use a real password here. | yes (local demo value) |
| `runId` | (empty) | run time | Set by the first request of every run (base-36 timestamp). Makes the space name and slug unique. | no |
| `spaceName` | (empty) | run time | Name of the space this run creates (`API Probe <runId>`). Set with runId. | no |
| `spaceSlug` | (empty) | run time | Slug of the created space. Captured from the inbox page. | no |
| `spaceId` | (empty) | run time | Public ID (ULID) of the created space. Captured from the Location header of the create call. | no |
| `testimonialId` | (empty) | run time | Public ID of the submitted testimonial. Captured from the inbox page. | no |
| `userName` | (empty) | run time | Display name of the signed-in owner. Captured from the profile page so the no-op profile update keeps it. | no |
| `xsrfToken` | (empty) | run time | URL-decoded XSRF-TOKEN cookie. Refreshed after every response. | no |
| `requestId` | (empty) | run time | X-Request-ID sent with the current request. Generated before every request; the response must echo it. | no |

| `foreignTestimonialId` | (empty) | you | Optional. Public ID of a testimonial in that foreign space (printed by the helper script). | no |
